Everything on this page is exported from `@munachi-me/numviz` 1.0.2. The optional React
components come from `@munachi-me/numviz/react`.

## Exports

| Export                    | Kind           | Description                                                    |
| ------------------------- | -------------- | -------------------------------------------------------------- |
| `createChart(config)`     | function       | Create a chart instance                                        |
| `createTable(config)`     | function       | Create a table instance                                        |
| `createMetric(config)`    | function       | Create a metric and compute its value                          |
| `createDashboard(config)` | function       | Create a dashboard                                             |
| `createReport(config)`    | function       | Create a report (a dashboard with presets)                     |
| `REPORT_PRESETS`          | object         | Built-in report layouts                                        |
| `version`                 | string         | Package version, `"1.0.2"`                                     |
| `NumvizError`             | class          | Error type with a stable `code`                                |
| `isNumvizError(value)`    | function       | Type guard                                                     |
| `Numviz`                  | default export | Namespace with the five factories, `version` and `NumvizError` |

## Data input

```ts
type DataRecord = Record<string, unknown>;
type DataMatrixRow = readonly unknown[];
type ColumnType = 'number' | 'date' | 'string' | 'boolean';

interface ColumnDefinition {
  readonly key: string;
  readonly label?: string;
  readonly type?: ColumnType;
}

type ColumnInput = string | ColumnDefinition;

interface DatasetLike {
  readonly columns?: readonly ColumnInput[];
  readonly rows?: readonly (DataRecord | DataMatrixRow)[];
  readonly data?: readonly DataRecord[];
}

type DataInput = readonly DataRecord[] | readonly DataMatrixRow[] | DatasetLike;
type NormalizedValue = number | string | boolean | Date | null;

interface NormalizedRow {
  readonly index: number;
  readonly values: Readonly<Record<string, NormalizedValue>>;
  readonly source: DataRecord | DataMatrixRow;
}

interface NormalizedColumn {
  readonly key: string;
  readonly label: string;
  readonly type: ColumnType;
}

interface NormalizedDataset {
  readonly columns: readonly NormalizedColumn[];
  readonly rows: readonly NormalizedRow[];
  readonly rowCount: number;
}
```

Input is never mutated. Numeric strings are normalized to numbers; unparseable values stay as
strings and are treated as missing by numeric aggregations.
