## createDataset

```ts
function createDataset(
  input: readonly Row[] | Readonly<Record<string, readonly unknown[]>> | Dataset,
  options?: DatasetOptions,
): Dataset;
```

Builds a dataset from records, column-oriented data, or another dataset. Raw cells go
through the normalization policy unless `normalization.inferTypes` is `false`.

```ts
createDataset([{ name: 'Ada', age: 36 }]);
createDataset({ name: ['Ada', 'Lin'], age: [36, 41] });
createDataset([{ a: 1, b: 2 }], { columns: ['b', 'a'], name: 'demo' });
```

| Option          | Default               | Meaning                                          |
| --------------- | --------------------- | ------------------------------------------------ |
| `columns`       | union of record keys  | Column order; required for column-oriented input |
| `name`          | `"Dataset"`           | Dataset name                                     |
| `metadata`      | `{}`                  | Read-only metadata                               |
| `normalization` | import default policy | Cell policy for raw input                        |

`new Dataset(rows, options)` builds the same object. `createNormalizedDataset(...)` is an
internal constructor for parsers and is not part of the public API surface.

## Inspection

| Method              | Returns                                                 |
| ------------------- | ------------------------------------------------------- |
| `head(count = 5)`   | `Dataset`                                               |
| `tail(count = 5)`   | `Dataset`                                               |
| `info()`            | `DatasetInfo`                                           |
| `column(name)`      | `ColumnView`                                            |
| `distinct(name)`    | `unknown[]` — distinct present values, first-seen order |
| `unique(name)`      | `unknown[]` — alias of `distinct`                       |
| `uniqueCount(name)` | `number`                                                |

`column()` throws `ColumnNotFoundError` for an unknown name.

```ts
data.info();
// { name, rowCount, columnCount, shape, dtypes, missingValues, memoryHint }

data.column('region');
// { name: "region", type: "string", values: [...], missing: 0, unique: 4 }
```

### Option types

```ts
interface DropMissingOptions {
  columns?: readonly string[];
  how?: 'any' | 'all'; // default "any"
}

type FillStrategy = 'mean' | 'median' | 'mode' | FillValue | ((row: Row, index: number) => unknown);
type FillValue = string | number | boolean | Date | null;

type ReplaceRule =
  | { from: unknown; to: unknown }
  | { from: readonly unknown[]; to: unknown }
  | { match: (value: unknown, context: ReplaceContext) => boolean; to: unknown }
  | ((value: unknown, context: ReplaceContext) => unknown);

interface SampleOptions {
  seed?: number;
  replace?: boolean; // default false
}

interface NormalizeTextOptions {
  whitespace?: 'trim' | 'collapse' | 'none'; // default "trim"
  case?: 'lower' | 'upper' | 'title';
  extraWhitespace?: readonly string[];
}
```

`ReplaceContext` is `{ row, column, index }`.

### Conditional columns

```ts
interface ConditionalRule {
  readonly when: (row: Readonly<Row>, index: number, context: ConditionalRuleContext) => boolean;
  readonly then: ConditionalThen;
}

interface ConditionalColumnOptions {
  readonly else?: ConditionalThen | ((row: Readonly<Row>, index: number) => unknown);
}
```

`ConditionalThen` is a static value or a callback. `else` defaults to `null`. The value is
cloned per row, so a shared object or `Date` is never aliased.

`addConditionalColumnReport` returns:

```ts
interface ConditionalColumnReport {
  readonly column: string;
  readonly rowCount: number;
  readonly matched: readonly number[]; // one count per rule
  readonly unmatched: number;
}
```

### Text normalization result

```ts
const { dataset, changes, changedRows } = data.normalizeText({ case: 'lower' });

interface CleaningChange {
  readonly column: string;
  readonly changed: number;
  readonly examined: number;
  readonly examples: readonly { row: number; before: unknown; after: unknown }[];
}
```

Non-string cells are left untouched. At most five examples are recorded per column.
